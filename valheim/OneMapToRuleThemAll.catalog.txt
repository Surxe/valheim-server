# OneMapToRuleThemAll — default object catalog (shipped)
# This is the catalog a fresh install starts from. It is AUTHORITATIVE and is
# never overwritten once written. Edit it to change what is tracked, or delete
# it and run om_gencatalog to regenerate against the current game version.
#
# Built from the game itself, not from keyword guesses:
#   category = the prefab's components
#   name     = HoverText, else the dropped item's localized name
#   icon     = the ObjectDB item the object actually drops
#   biome    = ZoneSystem vegetation/location data
#
# Rows are grouped by name: prefabs the game calls the same thing share one
# row, one toggle and one pin label. The exact prefabs behind each row are
# listed in the trailing comment, so identity is per-prefab, not by substring.
#
# COMMENTED rows are tracked=OFF by default. Uncomment to enable.
#
# Row ORDER is irrelevant: objects resolve by exact prefab name, not by
# substring, so rows are sorted purely for readability.
#
# Format:  Biome | Type | Keyword | Display | Abbr | Icon
#   Abbr defaults to the Display in PascalCase with separators removed
#   (Copper vein -> CopperVein). It is the label drawn on the pin, so edit
#   it freely; blank falls back to a Display truncation.
#
# Trailing comment: the exact prefabs behind the row, then the evidence for
# how it was classified.
#   bsrc=data     biome read from ZoneSystem vegetation / SpawnSystem / locations
#   bsrc=curated  no placement table lists this prefab; value hand-checked
#   bsrc=name     inferred from the prefab-name prefix (a guess)
#   bsrc=none     no biome could be determined at all
#   type/tier/pick/chop  the Destructible fields the Ore-vs-Tree call used
